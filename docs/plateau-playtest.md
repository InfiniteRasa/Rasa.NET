game client. `docs/plateau-mission-crossref.md` gives the sources of each mission. A checked box
(`- [x]`) means the playtest is done and the mission works.

Format: `- [ ] <mission id> <name> (<zone>): <what to look at>`.

## Deviations from the original game (client/server limits)

Places where a quest works differently from the live game because the server (or the client data we
have) cannot do it the original way. These are not estimates of values (rewards, places, levels):
those are in each mission's evidence. Format: `- <mission id> <name>: <deviation> - <reason>`.
